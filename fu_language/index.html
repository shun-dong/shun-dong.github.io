Fu：Agda 方言设计草案

0. 总目标

fu 是一门面向 Agda 的轻量方言。它不重新实现依赖类型论，不提供独立内核，不改变 Agda 的证明论语义。它只提供一层更接近个人数学记号习惯的表层语法，并翻译成标准 Agda 文件。

16. 和 Agda notation 的关系

fu 不依赖 Agda syntax declaration 实现主要语法，而是在翻译阶段直接输出核心 Agda 语法。

理由：

  1. Agda 自定义语法受 Agda parser 限制。
  2. ;、,、() 等在 Agda 里已有特殊用途。
  3. fu 想改变模块 block、行分隔、hole 表示，这已经超出 Agda notation 能力。
  4. 外部 transpiler 更自由，也更适合 Obsidian 集成。

Agda 自身的 syntax declarations 可以给函数应用定义绑定变量语法，但这仍然发生在 Agda parser 能接受的范围内。fu 的目标更接近外部 surface language。
